# Estatísticas de Criaturas

> Livro do Jogador (2024), p. 346–359.

## Estatísticas de Criaturas

Este apêndice fornece blocos de estatísticas para criaturas mencionadas em outras partes do livro, particularmente nos capítulos de classe, equipamento e magia. Veja também o glossário de regras para saber como ler um bloco de estatísticas e o Livro dos Monstros para ainda mais criaturas. Os seguintes blocos de estatísticas são apresentados em ordem alfabética. Quando o Mestre usa um bloco de estatísticas, ele pode alterar os detalhes no bloco.
