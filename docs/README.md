Estes documentos trazem mecânica: valores, tabelas, características, condições e descrições de
efeito. A prosa literária, a ficção e a arte do livro não estão aqui — para essas, a fonte é o
PDF. Regenerar: `python3 tools/gerar_docs.py todos`.
